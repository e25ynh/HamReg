# HamReg · ทะเบียนสมาชิกนักวิทยุสมัครเล่น

**HamReg** (Amateur Radio Member Registry) เว็บแอพไฟล์เดียว (`index.html`) สำหรับจัดเก็บข้อมูลสมาชิกนักวิทยุสมัครเล่น ไม่ต้องติดตั้งหรือมีเซิร์ฟเวอร์ ไม่ต้องใช้ API key และไม่มีค่าใช้จ่าย วางบน GitHub Pages ได้ทันที

## ทำอะไรได้

- เพิ่ม แก้ไข ลบสมาชิก (สัญญาณเรียกขาน ชื่อไทย ชื่ออังกฤษ ใบอนุญาตและวันหมดอายุ LINE อีเมล QTH โหมดและย่านความถี่ อุปกรณ์ หมายเหตุ)
- **เลขสมาชิกสร้างอัตโนมัติ** ดูหัวข้อถัดไป
- ค้นหา กรอง และเรียงลำดับรายชื่อ (ค่าเริ่มต้นเรียงตามวันใกล้หมดอายุ: ที่หมดแล้วขึ้นก่อน ตามด้วยที่ใกล้หมด ส่วนผู้พ้นสภาพอยู่ท้ายสุด)
- เอาเมาส์ชี้ที่แถวสมาชิกจะมีบัตรสมาชิกขนาดจริง 85.6 × 54 มม. เด้งขึ้นมา เอาเมาส์ออกก็หาย
- แจ้งเตือนวันหมดอายุ 3 ระดับ คือ ภายใน 90, 60 และ 30 วัน (สีเหลือง ส้ม แดง) บวกกลุ่มหมดอายุแล้ว กดที่ช่องแจ้งเตือนเพื่อกรองรายชื่อกลุ่มนั้น (ไม่นับผู้พ้นสภาพ)
- ปุ่ม **ต่ออายุ** ขึ้นที่แถวของสมาชิกที่บัตรหมดหรือใกล้หมดใน 90 วัน (และอยู่ในหน้าข้อมูลสมาชิกเสมอ) เลือกวันหมดอายุใหม่และวันที่ออกบัตรใหม่ได้ ระบบออกเลขสมาชิกใหม่ให้ เก็บเลขเดิมไว้ในประวัติการต่ออายุ ถ้าไม่ต่อให้กด "ไม่ต่ออายุ ตั้งเป็นพ้นสภาพ"
- คลิกแถวสมาชิกเพื่อเปิดหน้าข้อมูลสมาชิก มีรูปบัตรและรายละเอียดครบ พิมพ์บัตรลงกระดาษได้ (เลือกพิมพ์ขนาด 100%)
- ส่งออกและนำเข้า CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
- โหมดมืดและสว่าง

## รูปแบบเลขสมาชิก

`รหัสชั้น` + `วันที่ออกบัตร` + `-` + `เดือน` + `ปี ค.ศ. 2 หลัก` + `ตัวอักษรหน้าชื่ออังกฤษ`

| ส่วน | ความหมาย |
|---|---|
| B / I / A / N | ชั้นต้น (Basic) / ชั้นกลาง (Intermediate) / ชั้นสูง (Advanced) / ยังไม่มีใบอนุญาต |
| 19-1224 | ออกบัตรวันที่ 19 เดือน 12 ปี 2024 |
| T | ตัวหน้าของชื่อภาษาอังกฤษ (ชื่อต้น) |

ตัวอย่าง: ชั้นต้น ออกบัตร 19 ธ.ค. 2024 ชื่อ Thonphak ได้ `B19-1224T`

ถ้าซ้ำ ระบบเพิ่มตัวอักษรตัวที่ 2, 3, 4 ... ของชื่อเข้ามาแทน เช่น `B19-1224Th`, `B19-1224Tho` ถ้าไม่กรอกชื่ออังกฤษ หรือชื่อหมดตัวอักษรแล้วยังซ้ำ จะเติม `-2`, `-3` ท้ายเลข พิมพ์แก้เลขเองได้ทุกเมื่อ

เปลี่ยนรหัสชั้นได้ที่บรรทัด `var NO_CODE=` ใน `index.html`

## วางบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (แนะนำชื่อ `hamreg`)
2. อัปโหลดไฟล์ `index.html` และ `README.md` (ปุ่ม **Add file → Upload files**)
3. ไปที่ **Settings → Pages**
4. ตรง **Build and deployment** เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด **Save**
5. รอประมาณ 1-2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

## ใส่ชื่อชมรมบนบัตร

เปิด `index.html` หาบรรทัด `var CLUB_NAME='';` แล้วใส่ชื่อชมรม เช่น `var CLUB_NAME='THAI-AUSTRIAN CLUB';` ถ้าเว้นว่างบัตรจะแสดงคำว่า AMATEUR RADIO

## ข้อมูลเก็บที่ไหน

ข้อมูลสมาชิกเก็บใน **เบราว์เซอร์ของเครื่องที่ใช้งาน** (localStorage) ไม่ถูกส่งขึ้นอินเทอร์เน็ตและไม่ขึ้น GitHub แม้ repository เป็นสาธารณะ คนอื่นที่เปิดลิงก์เดียวกันจะเห็นหน้าว่าง

ข้อจำกัดที่ต้องรู้:

- ข้อมูลอยู่คนละชุดตามเครื่องและเบราว์เซอร์ เปิดจากเครื่องอื่นจะไม่เห็นรายชื่อ และเพื่อนสมาชิกเปิดดูรายชื่อจากลิงก์นี้ไม่ได้
- ถ้าล้างข้อมูลเบราว์เซอร์ (cache, cookies, site data) หรือเปิดในโหมดส่วนตัว ข้อมูลจะหาย
- **ส่งออก CSV สำรองเป็นประจำ** หน้าเว็บจะเตือนเมื่อยังไม่เคยสำรองหรือสำรองเกิน 30 วัน
- ย้ายเครื่อง: ส่งออก CSV จากเครื่องเดิม แล้วนำเข้าที่เครื่องใหม่ (นำเข้าจะข้ามสัญญาณเรียกขานที่ซ้ำกับที่มีอยู่)
- ไฟล์ CSV เก็บข้อมูลสมาชิกครบทุกช่อง แต่ไม่รวมประวัติการต่ออายุ
- ไม่ควรเก็บเลขบัตรประชาชนหรือข้อมูลบัญชีธนาคารในทะเบียนนี้

## ถ้าต้องการให้หลายคนใช้ข้อมูลชุดเดียวกัน

GitHub Pages เป็นเว็บแบบสแตติก ไม่มีฐานข้อมูลกลาง ถ้าให้กรรมการหลายคนกรอกและเห็นข้อมูลร่วมกัน ต้องเพิ่มบริการฐานข้อมูลภายนอก เช่น Supabase, Firebase หรือ Google Sheets แล้วปรับส่วน `storage layer` ในไฟล์ `index.html` (ฟังก์ชัน `loadAll`, `persist`, `remove`) อย่าใส่คีย์ลับหรือรหัสผ่านลงในไฟล์ที่อยู่บน repository สาธารณะ
